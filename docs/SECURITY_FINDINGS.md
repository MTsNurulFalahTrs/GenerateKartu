# Temuan keamanan dan integritas legacy

Temuan berikut berasal dari audit statis pada commit `623ce1280692d7c431ead92fdbdbd8427b0cba61`. Prioritas menunjukkan dampak potensial. Paparan pada deployment aktif dan eksploitasi belum diverifikasi. Nilai PIN tidak disalin ke laporan.

| ID | Prioritas | Bukti dan dampak | Perbaikan dan verifikasi |
| --- | --- | --- | --- |
| SEC-01 | P0 | Bootstrap membuat PIN awal dari literal kode di sheet tersembunyi. Aksi hapus membandingkan PIN bersama tanpa cek peran pada fungsi itu. [Code.gs L18–L69](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Code.gs#L18-L69) | Pensiunkan PIN. Jika komunitas diaktifkan, gunakan identitas, otorisasi server, pembatasan upaya dan audit. Uji penolakan anonymous dan lintas pengguna. Status penggunaan PIN awal pada deployment perlu diperiksa pengelola. |
| SEC-02 | P0 | QR memakai semua kolom format nonkosong. Format 1 memasukkan `Password` dalam kolom, sehingga QR dengan opsi aktif dapat membawa kata sandi bersama data peserta. Format 1 juga merender kata sandi pada teks kartu. [Index.html L3894–L3900](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L3894-L3900), [Index.html L7361–L7384](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L7361-L7384) | Gunakan allowlist QR minimal dan uji dekode tiap format. Tetapkan kontrak terpisah untuk kredensial tercetak dan uji ekspor serta aksesnya. |
| SEC-03 | P1 | Backup JSON masuk ke penyimpanan lalu aset TTD dirangkai pada atribut HTML. ID dari data komunitas juga dirangkai ke handler inline; escaping HTML saja tidak memberi keamanan konteks JavaScript. [Index.html L7099–L7119](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L7099-L7119), [Index.html L7350–L7358](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L7350-L7358), [Index.html L8293–L8357](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L8293-L8357) | Validasi skema, URL/aset dan ID. Pakai binding atribut/event tanpa markup atau handler yang dirangkai. Uji payload berbahaya pada backup, kartu dan komunitas. |
| SEC-04 | P1 | Ekstraksi ZIP membuat pekerjaan per entry tanpa batas eksplisit ukuran hasil ekstraksi, jumlah entry, atau konkurensi pada jalur tersebut. Foto rusak dapat dipertahankan sebagai data URL fallback. [Index.html L6619–L6683](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L6619-L6683) | Batasi ukuran, jumlah, dimensi dan konkurensi. Validasi decoding dan pertahankan data sebelumnya bila impor gagal. |
| SEC-05 | P1 | Library dan font dimuat dari pihak ketiga. Tailwind CDN tanpa versi. Script eksternal berjalan dalam dokumen pengolah data peserta. `ALLOWALL` mengizinkan framing aplikasi Apps Script. [Index.html L8–L15](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L8-L15), [Code.gs L12–L16](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Code.gs#L12-L16) | Kunci dan audit dependensi. Batasi sumber CSP dan framing sesuai kebutuhan, lalu uji integrasi cetak dan pratinjau. Kerentanan versi spesifik belum diverifikasi pada audit ini. |
| SEC-06 | P1 | Publikasi komunitas hanya memeriksa adanya nama dan baris serta nama duplikat. Cek duplikat dan append merupakan operasi terpisah, tanpa validasi struktur lengkap atau otorisasi eksplisit pada fungsi tersebut. [Code.gs L74–L119](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Code.gs#L74-L119) | Jika diaktifkan, gunakan skema ketat, validasi tipe/panjang, otorisasi, moderasi dan constraint unik. Uji submit paralel, masukan rusak dan akses lintas peran. |
| SEC-07 | P1 | Backup dan localStorage dapat memuat tanda tangan, NIP dan aset institusi. TTL di kode mengandalkan timestamp dan pembersihan di browser. [Index.html L4047–L4072](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L4047-L4072), [Index.html L5031–L5113](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L5031-L5113), [Index.html L6812–L6847](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L6812-L6847) | Tetapkan retensi dan klasifikasi aset. Uji backup, reset dan kedaluwarsa tanpa data asli. |
| SEC-08 | P0 | Kegagalan render per kartu ditangkap dan dicatat, lalu ekspor tetap disimpan dan jumlah sukses memakai total target. Kartu bisa hilang diam-diam. [Index.html L4744–L4765](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L4744-L4765) | Cocokkan jumlah dan ID kartu berhasil sebelum penyimpanan. Uji kegagalan render satu kartu dan validasi seluruh halaman PDF. |
| SEC-09 | P1 | Peserta ditetapkan ke state sebelum peringatan baris kosong dan ID duplikat. ID yang sama dapat mengacu ke foto atau QR yang sama. [Index.html L6367–L6419](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L6367-L6419), [Index.html L7327–L7373](https://github.com/r4nd1pr4t4m4-arch/generatorkartu/blob/623ce1280692d7c431ead92fdbdbd8427b0cba61/Index.html#L7327-L7373) | Validasi ID sebelum commit state impor. Uji penolakan duplikat dan ketepatan pemetaan aset. |
