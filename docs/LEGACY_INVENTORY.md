## Kontrak format dan keluaran

| Format | ID pencocokan | Kolom berurutan |
| --- | --- | --- |
| 1 Standar CBT | Username | NamaMurid, Kelas, Sesi, Username, Password |
| 2 Lengkap Ruang | NoPeserta | NoPeserta, NISN, NamaMurid, Kelas, Ruang |
| 3 Sederhana | NoPeserta | NoPeserta, NISN, NamaMurid, Kelas |
| 4 Identitas + Ruang | NoPeserta | NamaMurid, TglLahir, NISN, NoPeserta, Ruang |
| 5 Identitas Dasar | NoPeserta | NamaMurid, TglLahir, NISN, NoPeserta |
| 6 Identitas + Ruang + Satdik | NoPeserta | NamaMurid, TglLahir, NISN, NoPeserta, Ruang, NamaSatdik |
| 7 Identitas + Satdik | NoPeserta | NamaMurid, TglLahir, NISN, NoPeserta, NamaSatdik |
| Kustom/komunitas | Field dari konfigurasi format | Diturunkan dari baris builder, termasuk label dan opsi mono |

Kolom impor berasal dari `FORMATS`. Urutan cetak berasal dari cabang template `buildSingleKartuHTML` dan dapat berbeda. Misalnya, format 4 mencetak nama, tanggal lahir, NISN, nomor peserta, lalu ruang. Kolom kata sandi CBT adalah temuan privasi yang perlu dinilai saat menetapkan kontrak format.
